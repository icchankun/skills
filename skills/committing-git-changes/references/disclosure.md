# 会社・個人の情報の確認

ステップ5で、差分の追加・変更された行とコミットメッセージから、次のものを探す。

## 会社や個人が分かる情報・リンク

- 社名、自社のサービス名・製品名
- 社内のリポジトリ名・GitHub の組織名
- 会社のメールアドレスとドメイン
- 人の名前・アカウント名（リポジトリの持ち主の公開アカウントと noreply のアドレスは除く）
- ホームディレクトリから始まる個人のパス（`/Users/<名前>/` など。`~` や `$HOME` で書いたものは除く）
- 社内の URL（Notion・Slack・社内ツール・private リポジトリの GitHub など）

## 秘匿値につながる情報

- 社内のホスト名・IP アドレス・ポート
- クラウドのアカウント ID・プロジェクト ID・リソースの ARN
- 環境変数や設定の実際の値（名前だけなら当たらない）
- 秘匿値の置き場所を具体的に書いたもの（社内の Vault のパス・1Password の保管庫名など）

## 当たらないもの

- コードの例やテストで使う、それと分かるダミーの値（`example.com`、`foo`、`192.0.2.0/24` など）
- 公開されている OSS・サービスの名前と URL
