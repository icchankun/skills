# ブラウザで確かめる観点

自動テストでは拾いにくく、ブラウザで実際に触って確かめる観点。足す側のサブエージェントが、差分に関係する観点だけを当てる。

| 観点 | 確かめること |
|---|---|
| 見た目・レイアウト | 狭い画面幅での崩れ、長い文字列の折り返しとはみ出し、空の状態の表示、件数が多いときの表示 |
| 操作感 | キーボードだけで操作できるか（Tab・Enter・Esc）、フォーカスの移動、ボタンの連打で二重に送られないか |
| 読み込みと非同期 | 読み込み中の表示、遅い回線での動き、サーバーのエラーのときの表示、Turbo Frame / Stream などでの部分的な更新 |
| 画面の行き来 | 戻る・進む・再読み込みで状態が保たれるか、URL を直接開いたとき |
| 既存の画面への影響 | 同じ部品や CSS を使っているほかの画面が崩れていないか |
| ブラウザの違い | Safari での見た目と動き（日付の入力欄、スクロール、CSS） |
| アクセシビリティ | ラベルの読み上げ名、文字と背景の色の差（コントラスト）、エラーが色だけで伝わっていないか |
| 表示の形式 | 日時・タイムゾーン・数値・通貨の表示 |
| ファイル | アップロード・ダウンロード・印刷 |
