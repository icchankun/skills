# tuning-japanese-prompts

prompt-master は英語の依頼を前提に、よくない書き方を見つける。日本語の依頼は崩れ方が違うので、この skill の表で補う。

どう整えるか（対象ツールの見分け方、テンプレート、出力の形）は prompt-master に従う。この skill が足すのは、日本語に特有の見落としと、日本語での書き方だけ。prompt-master と食い違ったら、日本語の書き方についてはこの skill を、それ以外は prompt-master を優先する。

依頼した人の意図と、頼んだ中身は変えない。変えてよいのは、書き方・構造・範囲や完了条件の明示だけ。

## 1. 日本語の崩れ方を見つける

| 崩れ方 | 例 | 直し方 |
|---|---|---|
| 目的語の省略 | 「直しておいて」「確認して」 | 何を直すか・確かめるかを、ファイルや画面の名前で書く。会話から分からなければ聞く |
| 主語の省略 | 「テストが通らないので見て」 | 誰が・何が通らないのか（どのテスト、どのコマンド）を書く |
| 指示語 | 「これ」「あれ」「さっきの」「例の件」 | 指しているものの名前に置き換える。この会話で直前に出たものでも、名前で書き直す |
| ぼかした形容 | 「いい感じに」「よしなに」「きれいに」「ちゃんと」 | 何ができていればよいかを、確かめられる条件にする（「既存のテストが通る」「`src/auth/` の外は触らない」） |
| 依頼か相談か分からない文末 | 「〜かな」「〜してもいいかも」「〜したいですね」「〜とか」 | 変更してほしいのか、案や評価だけ欲しいのかを書く。決められなければ「案を出すだけで、変更はまだしない」寄りに倒す |
| 程度の副詞 | 「なるべく」「できれば」「ある程度」 | 必須か任意かを分ける。任意なら、やらない場合の扱いを書く |
| 「など」「とか」で終わる列挙 | 「不要な設定や重複など」 | 挙げた項目が例なのか全部なのかを書く。例なら、ほかに何を含めるかの基準を書く |
| 敬語とクッション言葉 | 「お手数ですが」「もし可能であれば」「〜していただけると助かります」 | 削る。指示の中身は変えない |
| 二重否定・遠回しの否定 | 「〜しないわけではない」「〜でなくもない」 | 肯定の形に直す |
| 箇条書きの体言止め | 「・不要設定の削除」 | 動詞で書く（「要らない設定を削除する」）。名詞だけだと、調べるのか直すのかが分からない |

## 2. 整えた版を日本語で書く

- 見出しも本文も日本語で書く。コマンド、パス、識別子、ツール名はそのまま。
- 指示は常体で、動詞で言い切る（「〜する」「〜しない」）。「〜してほしい」「〜してください」にしない。
- 1文に1つの指示を書く。「〜し、〜して、〜する」と続けない。
- 「適宜」「必要に応じて」は、何を見て決めるかを書くか、削る。
- 例を挙げるときは「例:」と書き、全部を挙げたものと区別する。

## 3. 直した点を伝える

整えた版の下に、変えた点とその理由を2〜4点書く。1の表のどれに当たるかが分かるように書く（例:「『いい感じに』を『既存のテストが通る』に置き換えた」）。
