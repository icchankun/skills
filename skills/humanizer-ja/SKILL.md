# humanizer-ja

日本語の文章から、AI が書いたように見える癖を取り除く。英語版の [humanizer](https://github.com/blader/humanizer)（`humanizer:humanizer`）と同じ考え方で、日本語で特に出やすい癖を足したもの。

言っている内容は変えない。事実・数値・固有名詞・リンクを足しも削りもしない。

## 進め方

1. 全文を読み、下の癖に当たる箇所に印を付ける。文単位だけでなく、段落の形も見る（毎段落同じ締め方をしている、など）。
2. 書き直す。印を付けた語句だけを差し替えるのではなく、その文が言いたいことを素直に書き直す。
3. 書き直した文を読み返し、まだ残っている癖と、内容の欠落・追加がないかを確かめる。

呼び出し元のスキル（git-commit など）から使うときは、仕上がった文だけを返す。

## 癖の一覧

上ほど強い。1〜5 は1回見つけただけで直す。6〜12 は単独なら書き手の癖の範囲なので、同じ段落に他の癖が重なっているときに直す。

### 1. 誰も言っていないことを否定する対比

「〜ではなく、〜です」「単なる〜ではありません」「〜というより〜」

否定する側を誰も主張していないなら、肯定の側だけを書く。読み手が実際に持っている誤解を正すときだけ対比を残す。

> ✗ これは単なるリファクタではなく、将来の拡張に備えた設計の見直しです
> ○ 通知の種類を足すたびに分岐が増えていたので、種類ごとにクラスを分けます

### 2. 念押しの締め

段落の最後で前の文を言い換えて繰り返す一文。「これが〜の本質です」「〜と言えるでしょう」「〜が鍵となります」「まさに〜です」

新しい情報がなければ消す。

### 3. 本題の前の前置き

「結論から言うと」「ポイントは〜です」「重要なのは〜という点です」「ここで注目すべきは」

前置きを消して本題から書く。

### 4. 三つ並べ

「A、B、そしてC」「迅速かつ正確、そして安全に」

意味の上で三つあるときだけ三つ書く。数を合わせるために足した項目は消す。

### 5. チャットの残り

「いかがでしたか」「お役に立てれば幸いです」「以下にまとめました」「素晴らしいご指摘ですね」「ご質問ありがとうございます」

全部消す。

### 6. ダッシュとコロン

「——」「―」で文をつなぐ、「A：B」で文を始める。

句点で切るか、「ので」「が」などの接続でつなぐ。

### 7. 大げさな言葉

「大幅に」「劇的に」「飛躍的に」「シームレスに」「堅牢な」「包括的な」「革新的な」「〜を実現します」「〜を可能にします」

効果を言うなら数字か具体的な挙動で書く。

> ✗ パフォーマンスが大幅に向上し、シームレスな体験を実現します
> ○ 一覧の表示が 1.2 秒から 0.3 秒になります

### 8. 翻訳調・冗長な言い回し

| 癖 | 直し方 |
|---|---|
| 〜することができます | 〜できます |
| 〜を行います / 〜が行われます | 動詞で書く（「検証を行います」→「検証します」） |
| 〜することが可能です | 〜できます |
| 〜という形で / 〜という点で | 消すか、具体的に書く |
| 〜に関して / 〜について | 「〜の」で足りることが多い |
| 〜的な | 消せるなら消す |
| フォーカスする / レバレッジする | 日本語で言える言葉にする |

### 9. 主語のない受け身

「〜が考慮されています」「〜が必要とされます」

誰が・何がそうするのかを書く。

### 10. 飾りの書式

- 箇条書きの先頭に太字のラベル（**ポイント**: 〜）を付ける
- 見出しや箇条書きに絵文字を並べる
- 見出しの直後の文で見出しを言い換える

普通の文にするか、ラベルを消す。コミットメッセージのテンプレートのように、決まった書式で指定されている見出しの絵文字はそのまま残す。

### 11. 同じ形の繰り返し

- 文頭が「また、」「さらに、」「そして、」ばかり
- 文末が全部「〜です。」、または全部体言止め
- 段落がすべて同じ長さ・同じ構成

文の長さと終わり方に揺れを付ける。接続詞は、ないと意味が通らないときだけ使う。

### 12. 英語由来の記号

- 「”」「“」の曲がった引用符 → 「」か `` ` ``
- 半角の「,」「.」を和文の読点・句点に使う → 「、」「。」

## 残してよいもの

- 書き手の文体。サンプルがあれば、文の長さ・語尾・記号の使い方をそちらに合わせる
- 技術用語やコード要素。カタカナ語でも、それが正式名称なら直さない
- 呼び出し元のスキルが決めている書式（git-commit の句点なし・敬体など）
